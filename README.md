## WTF is this??

Its 2007 again baby!! Hi5 Remix is a community bulletin board that brings back the GOLDEN ERA of the internet - when MySpace and Hi5 ruled, everyone had a Top 8, and your page auto-played Soulja Boy when someone visited.

This is a love letter to pimp-my-profile.com layouts, glitter GIFs, Comic Sans, `<marquee>` tags, and typing LiKe ThIs because we could.

## Features (OMG so many!!)

- **8 Skins** - Blue Heart Love, Ghetto Graffiti, Pink Bling, Galaxy Space, Scene/Emo, Tropical Paradise, Gold Chain, Anime Kawaii
- **Real-time Skin Switching** - Change ur layout every 5 minutes like we all did
- **Music Player** - 12 iconic 2007 bangers (Crank That, Umbrella, Girlfriend, Stronger...)
- **Bulletin Board** - Post on the wall!! Leave comments!! PC4PC??
- **Profile Card** - Editable username, mood selector, About Me section
- **Top 8 Friends** - The most important social hierarchy ever invented
- **Mood Selector** - 12 moods from "chillin" to "emo" to "dead"
- **Retro Widgets** - Hit counter, clock, shoutouts, web badges
- **Over-the-top Animations** - Marquee, blink, rainbow text, sparkles, floating particles, glow effects, shake, glitch
- **Floating Particles** - Hearts, stars, diamonds, fire emojis... depends on ur skin
- **Under Construction Banner** - Because every great page was always under construction

## The Vibes

Remember when...
- Your page took 45 seconds to load because of all the embedded music and glitter GIFs?
- You spent 3 hours picking the PERFECT layout from pimp-my-profile.com?
- Getting into someone's Top 8 was a bigger deal than a follow on Instagram?
- You had beef with someone so you moved them from #3 to #7 in your Top 8?
- "PC4PC" and "C4C" were the universal language of friendship?
- Your AIM away message was basically a blog post?

Yeah. Those were the days. This app brings them back.

## Tech Stack (way more advanced than GeoCities)

- React + TypeScript + Vite
- Tailwind CSS
- Pure CSS animations (no jQuery needed lol)
- YouTube IFrame API for the music player
- Deployed with love and nostalgia

## Getting Started

```bash
# clone it
git clone https://github.com/jdanjohnson/hi5-remix.git
cd hi5-remix

# install dependencies (faster than LimeWire downloads)
npm install

# start the dev server
npm run dev

# build for production
npm run build
```
